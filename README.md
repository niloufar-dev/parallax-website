## 🚀 Features

* 🎯 Smooth Parallax Scrolling
* 🖱️ Scroll-based animations
* 📌 Sticky and fixed elements
* 🌈 Dynamic gradient backgrounds
* 🖼️ Layered visual elements
* 📱 Fully responsive design
* ✨ Smooth transitions and animations
* 🎨 Modern interactive UI
* ⚡ Lightweight Vanilla JavaScript

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**
* **Tailwind CSS**

## 🎨 Main Concepts

This project focuses on:

* `position: sticky`
* `position: fixed`
* `transform`
* `opacity`
* `getBoundingClientRect()`
* `scrollY`
* Scroll-based animations
* CSS gradients
* Responsive design

## 📱 Responsive Design

The website is designed to provide a smooth experience across:

* 📱 Mobile
* 📱 Tablet
* 💻 Desktop

The mobile layout has been optimized to prevent overflow and animation issues on smaller screens.



## 🌟 Goal

The goal of this project was to explore **scroll-driven interactions, parallax effects, and modern web animations** while maintaining a responsive and visually engaging experience.

Through this project, I practiced combining **CSS positioning, JavaScript scroll calculations, gradients, animations, and responsive design** to create an immersive web experience.
